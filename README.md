# 최적화 확장형 영화 추천 엔진 (Optimized Movie Recommendation Engine)

## 프로젝트 개요
본 프로젝트는 C++ 기반으로 개발된 **협업 필터링(Collaborative Filtering) 기반 맞춤형 영화 추천 시스템**입니다. 
사용자들의 영화 평점 데이터를 분석하여 타깃 유저와 가장 유사한 취향을 가진 이웃(Top-K Neighbors)을 탐색하고, 아직 시청하지 않은 최적의 영화를 실시간으로 제안합니다. 특히, `std::unordered_map`을 활용한 다중 레이어 해시 인덱싱을 통해 대용량 데이터 환경에서도 탐색 복잡도를 `O(1)`로 압축하여 압도적인 성능을 자랑합니다.

## 빌드 방법 (Build Instructions)
본 프로젝트는 C++17 표준을 준수하며, 제공된 `Makefile`을 통해 간편하게 빌드할 수 있습니다. 소스 코드는 `src/`, 헤더 파일은 `include/`, 컴파일된 목적 파일(Object)은 `obj/` 디렉토리로 분리되어 관리됩니다.

1. **저장소 클론 및 디렉토리 이동**
~~~bash
git clone <repository-url>
cd <project-directory>
~~~

2. **전체 시스템 빌드**
~~~bash
make
~~~
* 명령어 실행 시 컴파일러가 가동되어 의존성에 맞게 목적 파일을 생성하고 최상위 디렉토리에 `main` 실행 파일을 빌드합니다.

3. **빌드 클린 (초기화)**
~~~bash
make clean
~~~
* 기존에 컴파일된 `obj/` 폴더 내의 `.o` 파일들과 `main` 실행 파일을 깔끔하게 삭제하여 충돌 없는 클린 빌드 환경을 준비합니다.

## 실행 방법 (How to Run)
수동 빌드 및 실행 과정을 단축하기 위해 통합 실행 명령어를 지원합니다. (실행 시 `data/` 디렉토리 내에 CSV 파일들이 위치해야 합니다.)

~~~bash
make run
~~~
* `make run` 명령어 입력 시, 소스 코드 변경 사항이 있다면 **자동으로 재빌드**를 수행한 직후 `./main`을 실행하여 즉시 추천 엔진 제어반으로 진입합니다.
> **Note:** 프로그램 실행 전 `data/movies.csv`, `data/users.csv`, `data/ratings.csv` 데이터셋이 정상적인 포맷으로 존재하는지 확인해 주세요.

## 주요 기능 (Key Features)
* **K-NN 기반 협업 필터링 추천:** 코사인 유사도(Cosine Similarity)를 통해 평점 성향이 비슷한 이웃을 다수 스캔하여 최적의 미시청 영화 Top-N 개를 제안합니다.
* **O(1) 고속 데이터 인덱싱:** 유저 ID 및 영화 제목 검색, 평점 내역 조회 시 선형 탐색(`O(N)`)을 배제하고 해시맵을 통한 즉각적인(`O(1)`) 데이터 접근을 구현했습니다.
* **실시간 데이터 파이프라인:** 새로운 평점이 등록되는 즉시 해당 영화의 누적 평점과 카운트가 실시간으로 동기화되어 데이터 무결성을 유지합니다.
* **안전한 예외 처리:** 평점 범위(0.0 ~ 5.0) 초과 시 자동 보정 및 데이터 타입 안정성(`static_cast<size_t>`)을 확보하여 컴파일러 경고(Warning) 제로를 달성했습니다.

## 클래스 구조 (Class Structure)
단일 책임 원칙(SRP)과 인터페이스 다형성을 준수하여 설계되었습니다.

* **`BaseManager` (Abstract):** 파일 로드/저장에 대한 인터페이스를 규정하는 최상위 추상 클래스
  * **`MovieManager`:** 영화 메타데이터 관리, 검색 기능, 추천 알고리즘 로직 및 통계 산출 담당
  * **`UserManager`:** 유저 데이터 파싱, 해시맵을 통한 고속 유저 정보 캐싱 담당
  * **`RatingManager`:** 실시간 평점 트래픽 관리, 유저별/영화별 다중 고속 인덱싱 맵핑 담당
* **`SimilarityCalculator`:** 두 유저 간의 평점 벡터를 분석하여 코사인 유사도를 계산하는 유틸리티
* **`Movie`, `User`, `Rating`:** 도메인 데이터를 캡슐화하고 연산자 오버로딩(`==`, `<`, `<<`)을 구현한 Entity 클래스

## 확장 기능 (Extended Features)
기본적인 영화 추천 시스템의 한계를 넘기 위해 아래와 같은 심화 확장 기능을 구현했습니다.

1. **지능형 검색 알고리즘 (Search Enhanced)**
   * **부분 일치 및 대소문자 무시 검색:** 검색어와 원본 제목을 모두 소문자로 치환(`toLowerCase`)하고 `std::string::find`를 활용하여, 제목의 일부 키워드만 입력해도 일치하는 모든 영화를 찾아냅니다.
2. **실시간 통계 및 CSV 익스포트 (Data Analytics)**
   * 플랫폼 누적 평균, 총 등록 건수, 최다 보유 장르 등의 인텔리전스 리포트를 실시간 대시보드 형태로 출력합니다.
   * 연산된 랭킹 차트 결과물은 단일 책임 원칙에 따라 분리된 전담 함수(`exportStatisticsToCSV`)를 통해 `data/statistics_report.csv` 파일로 안전하게 별도 저장되어 외부 툴과의 연동성을 극대화했습니다.
